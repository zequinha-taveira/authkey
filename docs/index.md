# authkey-sdk Documentation

Welcome to the `authkey-sdk` documentation. This library provides a professional, vendor-neutral Python interface for interacting with FIDO2 Security Keys.

## Features

- **Device Discovery**: Automatically detect HID-based FIDO2 security keys.
- **Registration**: Simple API for `makeCredential`.
- **Authentication**: Easy assertion signing for `getAssertion`.
- **Security Focused**: Built with threat modeling and secure coding practices.

## Quick Installation

```bash
pip install authkey-sdk
```
