# Security Policy

## Supported Versions

We provide security updates for the following versions of `authkey-sdk`:

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |
| < 0.1.0 | :x:                |

## Reporting a Vulnerability

We take the security of `authkey-sdk` seriously. If you discover a security vulnerability, please do NOT open a public issue. Instead, report it privately to our team.

Please send an email to **security@authkey.io** with a description of the vulnerability and instructions on how to reproduce it.

### What to Expect

- We will acknowledge receipt of your report within 48 hours.
- We will provide a timeline for addressing the issue and keep you updated on our progress.
- Once a fix is released, we will give credit to the reporter (unless you prefer to remain anonymous).

Thank you for helping keep our users safe!
