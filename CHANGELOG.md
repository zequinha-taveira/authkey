## [0.1.0] - 2026-02-14

### Added
- Initial project structure for `authkey-sdk` library.
- Core modules: `client`, `device`, `models`, `exceptions`, `crypto`, `config`.
- Basic device discovery using `python-fido2`.
- `makeCredential` and `getAssertion` logic in `SecurityKeyClient`.
